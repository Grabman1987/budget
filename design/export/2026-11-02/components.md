# Reconciled shared component contract

Generic derivative of components/buttons.md, forms.md, status-feedback-navigation.md and blueprint-charts.md, with DESIGN-SYSTEM.md and DECISIONS.md as visual context. These are references for composing existing @budget/ui primitives, not new component APIs or validated behavior.

| Source pattern                                      | Existing foundation / constraint                                                                                                                                                                                         |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Primary, secondary, ghost, danger actions           | Reuse current buttons; one primary action per region, visible focus, busy/disabled semantics and 44px phone hit areas. Red actions need actual action-needed/destructive meaning.                                        |
| Fields, arithmetic amount, date, combobox           | Reuse fields, AmountInput and DateInput, native labels and current validation. Enter/Escape/blur behavior follows the owning approved flow and existing commit guards.                                                   |
| Dialog and phone form sheet                         | Input/confirmation only, focus containment and return, dirty-form guard. Details use real sub-pages; search and Plan-month inspector keep their explicit exceptions.                                                     |
| Circled c, double check, lock                       | Present pending, confirmed and reconciled states using existing status words/accessible names. Cash starts confirmed, bank retains its pending default. Locks stay read-only.                                            |
| Budget presentation marks                           | Existing determined state only: target met blue/check; open amber/partial pie; overspent red/appropriate icon; more-than-target green/up; zero/paused neutral/dash. Never derive new thresholds here.                    |
| Maßkette, Schriftfeld, Stückliste, Revisionstabelle | Reuse DimensionChain, TitleBlock, PartsList and RevisionTable; existing queries/domain logic supply figures and line items. No static source arithmetic in production.                                                   |
| Chart, legend and tooltip                           | Use shared chart primitives, actual stored dates, unit/scope/as-of labels, keyboard inspection and table alternative. Privacy masks every value including tooltip/accessible text.                                       |
| Tabs, selected rows, dropdowns                      | Semantic native controls, selection independent of color, preserved URL/deep-link and browser-back context. No second navigation system.                                                                                 |
| Empty, loading, offline, error                      | Per-section loading/error and clear next action where appropriate; retained queued-write/recovery semantics. A visual reference cannot forbid a necessary page-level error or replace an honest failure with a skeleton. |

Solid = actual, dashed = plan/projection, dash-dot = previous period. Need is solid, want hatched, future cross-hatched; debt is dashed outline without fill. Historical report negatives keep signs and quiet ink. Preserve zero geometry, missing-versus-zero distinction and chart-label size at narrow widths. Use motion only with reduced-motion support; no animation fabricates a value or hides a failed operation.

Source confirmation eligibility, contact forgiveness, balance reconciliation and automatic-saving examples are not new policies. Preserve the current approved #563/#741/#818 boundaries, explicit preview, stale-revision/conflict guards, locks, audited grouped writes and Undo. The source's separate Split-mode wording loses to the current unified booking-line directive; no new Split-mode switch is imported.
