Dimension chain (Maßkette): terms on a dimension line with slash terminators that add up to a result.

```jsx
const { BlueprintMaKette } = window.BudgetBlueprintDesignSystem_63932b;
<BlueprintMaKette text1="Anfang" text2="10.000 €" text3="Eigenleistung" text4="10.000 €" />
```

- Fixed Figma geometry; override size via `style`. Text via `text1…text4` (or `children` for the first text).
- Colours follow the Zielsystem tokens — wrap in `data-mode="dunkel"` for the Blueprint dark look.
