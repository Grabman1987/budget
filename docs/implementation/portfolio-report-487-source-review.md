## Finding

**P2 — Default print omits the annual return grid.** The Rendite & Risiko reader wraps its year-by-month table, including the canonical `history.years[*].rate` annual return column, in a `<details>` without `open` (`apps/web/src/pages/portfolio-performance-comparisons.tsx:184-190,229-282`). The new "Register drucken" action calls `window.print()` directly (`apps/web/src/reports/portfolio-analysis-report.tsx:43-51`), while the new print CSS only hides navigation and adjusts tables; it does not expose a closed details body (`apps/web/src/reports/portfolio-analysis-report.css:25-52`). On the default report view, selecting print before expanding "Renditeraster nach Jahr und Monat anzeigen" therefore omits the entire annual grid from the printed register. This is a source-level consequence of native closed `<details>` rendering; the package states that printing covers the selected register. A minimal fix is to include the grid in print regardless of its on-screen disclosure state, such as a print-only table copy or a print lifecycle that opens and restores the disclosure. Preserve the default collapsed screen state.
