The literal test inventory comes from the approved baseline, alias plan and retained #620/T6
contracts. It is compared bidirectionally with the actual constructed router. Each flag mode
imports a fresh tree; a mutable flag on a reused alias tree would give a false OFF result.

and six dev routes, the current development tree has 83 accounted patterns. Production-mode
construction excludes all six dev patterns. Generic report matching is expanded to the actual
current hub identities and the planned stable identities' currently working destinations.

Browser probes are separate from route matches. They use real sample readers and the existing
isolated import-detail lifecycle, real supported views, loaded bodies, retained query/hash,
Back and reload. Sample contacts deliberately have no contact-bearing splits: their loaded
zero state and retained history entry are tested explicitly. Salary's absent current September
slip is separate from the populated August primary body. Unknown report/presentation/saved-view

dirty-draft discard before requiring zero booking/payee writes and an empty booking readback.
