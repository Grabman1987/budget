# UX V1 — Vermögen (#480)

This package implements C-08, C-09, C-21, C-23, C-24 and C-27. All development data is synthetic. The original audit images for portfolio, debt and freedom were reviewed locally; the referenced instrument/savings audit shots are absent from this checkout. Figma financial values were not fetched or copied.

The saving default reuses the existing Zukunft allocation calculation for up to six closed budget months, with refunds netted, rounded in integer cents and clamped at zero for the editable nonnegative scenario. Unsafe sums remain unavailable. The portfolio return/history reuses the Reports query. Debt history uses actual monthly EUR valuations, so its direction reflects the ledger. A falling curve is never fabricated.

Savings purchases include recorded gross buys for the selected instrument/account since the earliest stored plan version, including manual buys. Fees and taxes are separate columns. The next planned date resolves inclusive version dates and short months; ended or ambiguous versions do not produce a definite next execution. Forms, locks, writes and undo are unchanged.
