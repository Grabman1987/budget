## A. Deploy and CI (before the first deploy) — P1f-1

- **A1 High — deploy not gated by CI.** `ci.yml:3-4` runs on `pull_request` only; `deploy.yml:3-5` deploys every push to `main`. Fix: `deploy.yml` triggered by `workflow_run` of CI on `main` with `conclusion == success` (or a `needs:` test job); document branch protection for `main` (require PR + `check`, `docker`, `restore-test`); GitHub Environment `production` holding `FLY_API_TOKEN`, `main` only; add `workflow_dispatch`.
- **A2 High — Fly token exposed to an unpinned action.** `deploy.yml:17-18` job-level `env: FLY_API_TOKEN`; `deploy.yml:32` `superfly/flyctl-actions/setup-flyctl@master`. Fix: pin all actions to commit SHAs (version comment), token only in the `env` of the deploy step, `persist-credentials: false` on checkout.
- **A3 High — first deploy can create two machines with two databases.** `deploy.yml:34` lacks `--ha=false`; docs tell the owner to set the GitHub secret before the first manual deploy. Fix: `--ha=false`, a guard step failing if more than one machine exists, reorder `docs/ops.md` §3 and `docs/CLOUD-SETUP.md` §5 (GitHub secret only after the first manual deploy; CLOUD-SETUP points to ops.md).
- **A4 High — lockfile out of sync.** `apps/web` wants `jsdom ^27.4.0`, lock has 30.1.1 (`npm ls` → ELSPROBLEMS). Fix: one jsdom major in all workspaces, regenerate lockfile.
- **A5 Medium — backup can be silently off.** Entrypoint replicates only when `BUCKET_NAME` exists. Fix: `BUDGET_REPLICATE = '1'` in `fly.toml [env]` so a missing bucket fails at start.
- **A6 Medium — no app rollback runbook.** Add to `docs/ops.md`: `fly releases` → `fly deploy --image …:deployment-<id> --ha=false`; rule "migrations are additive only"; verify the Litestream metadata folder name (`.budget.sqlite-litestream`?) and the `litestream ltx/status` commands used in §3.7/§6; recovery script as user `node`; first-boot health-check `grace_period` ≥ 60 s.
- **A7 Medium — Windows/local dev broken.** (a) `packages/db/src/client.ts:16-17` uses `new URL('../drizzle', import.meta.url).pathname` → broken on Windows and paths with spaces; use `fileURLToPath`. (b) `npm ci` tries `node-gyp rebuild` for better-sqlite3 although prebuilt binaries exist → add repo `.npmrc` with `ignore-scripts=true`, remove build tools from the Dockerfile; copy only `linux-*` prebuilds (Dockerfile:65). ## B. Auth and security (before real data) — P1f-2

- **B1 High — audit log flood.** `app.ts:63` origin guard runs before any limiter; `auth/routes.ts:164-171` logs every rejection with the raw Origin (≈16 KB); `auth/store.ts:238-254` no cap/retention → volume fill, outage. Fix: rate-limit/deduplicate before logging, truncate `detail` to 100 chars, prune `auth_event` after N days.
- **B2 High — recovery sessions cannot be revoked.** `routes.ts:427` creates sessions with `passkeyId: null`; `store.ts:68-79` revokes only by passkey; `recovery/regenerate` (`routes.ts:432-439`) keeps sessions. Fix: revoke recovery sessions on regenerate and passkey revoke; step-up-protected "Alle anderen Sitzungen beenden"; correct ops.md §7/§9.
- **B3 Medium — no body limit.** `app.ts:60-66`; `c.req.json()` buffers everything. Fix: `bodyLimit({ maxSize: 64 * 1024 })` on `/api/*` before the origin guard.
- **B4 Medium — recovery codes unsalted SHA-256.** `auth/crypto.ts:43-44`, 60-bit codes. Fix: HMAC-SHA-256 with a server pepper (Fly secret) or scrypt/argon2id per code; consider ≥ 80-bit codes.
- **B5 Medium — backup not encrypted client-side.** `litestream.yml:15-25`, ops.md marks the age copy "not implemented". **Release blocker before real data:** implement the nightly age-encrypted copy (or equivalent client-side encryption).
- **B6 Medium — rate limiter.** `rate-limit.ts` unbounded Map, full scans beyond 10k keys; IPv6 keyed per address. Fix: key IPv6 by /64, cap size (evict oldest), global ceiling per limiter.
- **B7 Low.** Chown only `/data`, keep `/app` root-owned read-only (Dockerfile:73); revoke previous session on re-login (`routes.ts:134-156`); re-set cookie when sliding expiry (`routes.ts:123-155`); HMAC the IP hash (`routes.ts:100`); add `Permissions-Policy`; `umask 077` in entrypoint; setup token via `fly secrets import` (stdin) in docs; auth events visible later in Einstellungen › Sicherheit and recovery logins/new passkeys into the Posteingang (P3).

## C. Data model and domain (before P2) — P1f-3

- **C1 — envelope rollover.** `domain/ledger/envelope.ts:35` carries negative available forward; concept §5.3 and `design/prototype/plan.js:115,134-135`: carry `max(0, prev)`, uncovered overspending reduces next month's "Zu verteilen"; fixed/invest/debt kinds per concept. `toBeAssigned` (envelope.ts:41-47) lacks the overspending term. - **C2 — "Zu verteilen" ignores on-budget status.** `db/repos/queries.ts:60-79` counts depot buys and loan interest as uncategorised activity; line 73 treats every uncategorised transfer leg as neutral; `createTransfer` (`repos/bookings.ts:241,253`) allows a category only on the outflow leg. - **C3 — income.** `schema/budget.ts:12,33` class NOT NULL need/want/future → add income categories/kind and an `income_type` table (Gehalt, Sonderzahlung, Beiträge von Kontakten, Nebeneinkünfte, Kapitalerträge, Erstattungen, Geschenke) with `booking_split.income_type_id`; stop detecting special payments by memo (`figures.test.ts:127`); define the meaning of `booking_split.contact_id` (receivable share per concept §3.4, not salary counterparty).
- **C4 — transfers.** Split-level transfer link (concept: Anteil = category, contact or transfer; Actual allows transfer splits) with invariant counterpart = −split amount; `importTransfer` idempotent (skip existing pair, repair one-legged pair).
- **C5 — balance rule disagrees.** Domain `accountBalances` (`ledger/balances.ts:77,83`) vs SQL (`queries.ts:29-48`) around the opening date. Pick one rule, apply in both, edge-case test with an account opened after 01.10.2023.
- **C6 — account type and budget status.** `schema/accounts.ts` has only `role`. Add `type` (Giro, Bargeld, Tagesgeld, Kreditkarte, Kredit, Depot, Krypto, P2P, Sonstiges) and explicit `on_budget`; document how `reserve` counts.
- **C7 — foreign currency.** Signed `original_amount_cents`; CHECK all-or-none for fx fields; repository validation `amount ≈ original × rate + fee`; set `fx_fee_cents` in fixtures.
- **C8 — undo can break invariants.** `repos/audit.ts:306-322,382-403`: single-entry undo on split/transfer tables. Allow only group undo there or re-validate inside the undo transaction.
- **C9 — extend CHECK enums now** (SQLite needs table rebuilds later): trade kinds (tax, fee, dividend, interest, delivery in/out, split), category kinds (income), account types.
- **C10 — portfolio.** `repos/portfolio.ts:204-211` holdings by security across accounts → key by (account, security), value per account, test it and use it in `figures.test.ts` instead of the local `positions()`; cost basis FIFO alongside average (Gate 3 vs PP); currency conversion for non-EUR prices/accounts; implement TTWROR/IRR/Modified Dietz with cash flows in the domain.
