## Additional code-review items

These are source-level findings, not additional reproduced end-to-end cases:

- Manual price PUT uses external-series upsert without a user audit/undo group. Separate manual user decisions from automatic market updates.
- First price insert creates no price-change audit row; a refresh time derived only from changes can miss the first successful refresh.
- Review assumptions about past unmaterialized expected income and missing FX before accepting the Heute UI.
- Fixture tests do not establish live provider contracts. Ariva is explicitly unverified/off by default; see `docs/market-data.md`.
