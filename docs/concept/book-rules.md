# Book-derived finance checks

This English specification records the accepted product scope. It contains no household analysis or private owner values. The authoritative rule registry is `RULE_CODES`; the UI derives available and enabled counts from that registry and the stored enabled flags.

The ideas draw on Financial Order of Operations, The Millionaire Next Door, Just Keep Buying, The Psychology of Money, The Simple Path to Wealth and I Will Teach You to Be Rich. These are configurable planning checks, not investment recommendations. R23 (fund reporting status) is deferred.

| Rule | Stage | Calculation and configurable defaults |
| --- | --- | --- |
| R17 Gross investment rate | 2 | Net deposits from budget into investment accounts, including security deliveries, plus employer pension contributions, divided by actual payslip gross over the trailing calendar year. Target 2,500 bp; warning from 1,500 bp; maximum severity bad. Employer contributions included by default; own-only rate shown separately. Loan repayments and reinvested income do not count. |
| R18 Wealth benchmark | 2 | Expected wealth = age in months × trailing-year gross income / 120; actual net worth / expected wealth. Index target 100, lower benchmark 50 (hundredths); above-average benchmark 200, minimum age 25. Capital income included by default, configurable. Warning only; no red status. Side income included. Pension claims and pension-fund balances are excluded; inheritances cannot retrospectively be separated. |
| R19 Marginal saving rate | 3 | Compare the last twelve completed budget months with the preceding twelve, using R01 household income and Future assignments. Below 300 bp income growth: fulfilled, not applicable. Otherwise delta Future / delta income: target 5,000 bp, warning from 2,500 bp. |
| R20 Investing regularly | 2 | Last twelve completed months with a buy or investment deposit. Target 11 months; warning from 9. Extra debt repayment qualifies by default only when R09's configurable expensive-debt threshold prescribed repayment first. An incomplete history can produce a false result. |
| R21 Leverage and platform debt | 2 | Leveraged position value / total investment value: limit 1,000 bp, bad more than 500 bp beyond it. Negative platform clearing balances: ignore individual balances up to 10,000 cents; warning from 1 bp, bad above 500 bp. Worst component wins. Net leverage exposure is displayed separately against equity. R09 covers loan accounts, so loan accounts are excluded here. R15 is unchanged. |
| R22 Fund costs | 3 | Market-value-weighted TER over ETF/fund positions. Limit 30 bp, bad more than 30 bp beyond it. Leveraged funds excluded by default and listed separately. TER zero means unknown; above 20% unknown fund value the rule is unavailable. Within that allowance, the displayed ratio weights known TER only and identifies the missing coverage. Last-year trading fees / average daily security portfolio value is display-only; tax is excluded. |

All thresholds and inclusion switches use the existing strict, audited parameter PATCH. Integer cents, basis points, integer tenths of leverage and BigInt-safe multiplication are used. R18's severity is deliberately restricted to warning. Rules start disabled and can be previewed before activation. Existing rules, settings and results are not changed by default seeding; newly missing rows are added idempotently.

R17/R18 need payslips for every completed month of the twelve-month reference window, including special payments and bonuses in actual gross. Tax-free reimbursements do not add to gross. Dated flows use the trailing calendar-year interval ending at the evaluation date, with leap-day anniversaries clamped to month end. Employer contributions accrue proportionally over calendar days and require an explicit monthly record, including zero, for each overlapping month. R19 requires 24 completed budget months; R20 requires twelve completed months of history. Missing sources produce no status and a visible explanation.

Birth month/year is an optional private database setting with no default; the UI asks for no day. Employer contributions are monthly, audited, undoable records. Instrument forms expose TER and a leverage factor (default 1.0×, stored as 10). Historical evaluations clip bookings, trades, balances, prices and income to the evaluated day; instrument metadata and rule parameters use the currently maintained values. Results are derived idempotently for twelve month ends plus today when the report opens.

S2-1 links to R17. S3-2 keeps one checklist row and requires both R22 costs and R13 allocation bands to be fulfilled and enabled. Existing manual confirmations remain stored; derived links take precedence. S2-3 points to R10 and R17 alongside its existing R01 link. Heute key rules remain unchanged; its denominator follows enabled rules. R16 additionally displays months of freedom with 12/24/60-month milestones, without changing its status calculation.

Before enabling these rules, enter complete payslips and trades, birth month/year if using R18, monthly employer pension contributions, missing fund TER and correct instrument leverage factors. No provider integrations or automatic budget postings are introduced.

Related reports display R17 in savings (including a second line from stored monthly results when enabled), R19 beside the existing salary-report placeholder, R21 in allocation and R22 in costs/taxes. Their current rolling-year figures explicitly identify the evaluation day and disabled preview state. The salary report itself remains outside this implementation.
